### Current-market panel discipline

- Radar signal (`>=10 posts / >=4 weeks`): discovery only
- Decision-panel signal (`>=15 / >=6`): directional screening
- Strict-panel signal (`>=20 / >=8`): sensitivity evidence
- Left-censored creator: unresolved, never failed
- Automated feature code: exploratory only because the Stage-0 reliability gate failed; it cannot admit a topic

The generated Scout Queue is a discovery screen, not an evidence gate or ranked topic list. A
`screen_A` row means multiple corpus layers surfaced the same automated combination; it still
needs a named practitioner pain, primary/public proof, artifact feasibility, and Tiger's source
note before scoring.
