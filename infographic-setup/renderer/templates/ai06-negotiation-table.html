A 9% ask is not one number. It is a stack of claims — and you answer each one against the cost line it actually hits, not the headline.

The method underneath every counter: a should-cost build (material + labour + overhead + freight + margin), then tie any change to a public index — new price = base × (current index ÷ base index). A published number is harder to argue with than a claim.

Claude builds the map, sharpens the questions, and role-plays the supplier — it is your rehearsal partner, not a source of facts. It cannot see the supplier's private costs, and it will guess at index numbers. Treat every figure as unverified until you check it against the real source (LME, BLS, Eurostat).
