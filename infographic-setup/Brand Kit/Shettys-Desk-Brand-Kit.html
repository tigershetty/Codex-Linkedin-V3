Brand Essence

Shetty's Desk is an optimistic, credible, modern visual voice for professional content. Airy white space, luminous blue gradients, and a vivid green that always signals positive / progress / the smart choice. Coral marks the old or costly way, used sparingly. Everything is rendered as smooth isometric 2.5D vector art — never photographic. Three things make it instantly recognizable: the signature green→blue gradient, the flat isometric illustration, and mixed-weight stat callouts.

Personality

Optimistic, credible, modern, calm. Data-driven but human — friendly figures and speech bubbles keep it approachable.

V4 default

One native operating scene: a live reader tension, one physical mechanism, and one useful keep. Modules are for explicit carousels and precision artifacts.

Color logic

Blue = the system / neutral. Green = positive / progress / the win. Coral = negative / cost / the old way.

The two-layer rule

The logo palette is the identity layer (terracotta/olive, textured, serif, dark canvas); the azure/eco system is the content layer. Keep them apart. Use a small exact logo only on an approved carousel or precision artifact; do not paste it over a native feed scene. Never stretch, recolor, outline, or AI-regenerate the mark.

Illustration & Iconography

The brand has two deliberate visual modes: a standard feed post uses a tactile Commitment Object — a bespoke operating instrument that makes a decision visible; an explicitly selected carousel or exact artifact uses flat-design isometric / 2.5D vector art. The palette and colour meanings stay constant; the visual mechanism serves the argument.

✓ Do

  • For a standard feed scene: one Commitment Object with visibly causal mechanics
  • For an exact artifact: isometric or front-flat vector with smooth gradient fills
  • Green gradient reserved for the positive / highlight element
  • Soft, diffused long shadows (never harsh or black)
  • Friendly mini-figures + green rounded speech bubbles
  • Generous negative space; one clear focal object

✗ Don't

  • No generic warehouse stock photography or disconnected decorative props
  • No hard black outlines or hand-drawn sketch look
  • No dark or busy backgrounds
  • Don't use green for anything negative/costly
  • No harsh or black drop shadows
  • Avoid clutter — keep it editorial and airy

Layout & Format System

Use these modules only for an explicitly selected carousel or precision artifact. A standard feed post starts with one operating tension and is rendered as one native composition, not assembled from this layout.

1 · Pin header

A number/topic badge + UPPERCASE title, underlined by a thin azure rule that fades to the right.

2 · Intro + character

A short light paragraph paired with a mini-figure and a green speech bubble holding a topic icon.

3 · Concept row

A row of 3–4 isometric icons, each with a bold label + 1-line caption. The workhorse module.

4 · Hero scene

One large isometric illustration as the centerpiece, lots of white around it.

5 · Stat callout

An oversized mixed-weight number (green positive / coral negative) + caption.

6 · Sources footer

Centered small blue "Sources:" list. Citing data is part of the credibility.

Precision-Artifact Prompt Studio

For a standard LinkedIn post, use the V5 Native Scene block in PROMPT-LIBRARY.txt: reader tension, a Commitment Object, useful keep, one native composition. This studio is for module-based carousels and exact artifacts.

Precision-artifact style block (only for a carousel or exact card)
Flat-design isometric 2.5D vector infographic illustration in the "Shetty's Desk" brand style. Smooth blue gradients (azure #2798FB → royal #247BE1 → deep navy #1939A5), rounded geometric shapes, soft diffused long shadows, subtle glows, clean editorial composition on a pure white background. A signature green eco-gradient (mint #8FF3CC → emerald #38E6A6) marks the positive / progress / highlighted element; coral-pink #E27199 marks any negative / warning element, used sparingly. Modern, optimistic, science-led, tech-forward. Crisp vector — NOT photorealistic, no 3D render, no hard black outlines, no sketch texture, no dark backgrounds.

Tip: paste the prompt, then drag in 1–2 reference thumbnails from the References section and say "match this art style, not the subject." Re-run with the same prompt + a new subject to extend the series.

Tool-Specific Tips

Gemini — Nano Banana Pro

  • Strong at reference-image consistency — attach 1–2 kit images and ask it to keep the flat isometric style.
  • Handles long prompts; keep the full style block intact.
  • Renders in-image text well — fine for labels / stat numbers.
  • State aspect ratio explicitly; iterate in the same chat.
  • Ask for a row of matching icons in one shot for consistency.

ChatGPT — Image 2

  • For a standard feed post, lead with the V5 Native Scene block and a Commitment Object — not "flat-design...".
  • Use the identical flat style block only within the precision-artifact route.
  • Conversational refinement is its strength — start full, then nudge.
  • Excellent text rendering — good for stat-callout modules.
  • Ask for pure-white background so assets drop into layouts cleanly.

Claude Code — exact artifacts

  • Point it at brand-tokens.json + the style guide as the source of truth.
  • For normal feed posts, write one native image-engine prompt from the Operating Studio frame.
  • Use editable HTML/SVG modules only for a separately selected carousel or exact artifact.
  • Best for pixel-precise, fully editable, repeatable output when exactness is the reader value.
  • Never assemble modules as a layer over a native scene.

Standard feed post: one decision, one visual mechanism, one native image. Precision artifact: modules may be assembled when exact controlled layout is the actual reader value.
