# Layout Select

Make the visual structure carry the argument. Start from the selected Creative Genome elements, not a generic layout menu.

## Load the decision

1. Read `reference-bundle.json`, the applicable support ledger or support file, and `creative-brief-lite.md` when present.
2. Inspect every selected visual reference directly. Require `visually_verified` status.
3. State the visual argument in one sentence: `The reader understands [claim] because the image shows [relationship].`
4. List the exact claim IDs, labels, numbers, formulas, logos, and artifact controls the image must preserve.

## Choose the layout

1. Use the bundle's visual element as the primary structure.
2. Translate its mechanism into the current supply-chain decision and Cobalt Grid brand frame.
3. Choose one hero, one eye path, one density level, and one decisive contrast or transition.
4. Use `references/layout-frameworks-intelligence.md` only to implement or challenge the selected structure. Do not begin by browsing all layouts.
5. Select GPT Image 2 for editorial illustration and composition. Select HTML/code-render when exact tables, formulas, charts, timelines, or repeated labels carry the value.
6. Reserve deterministic zones for exact logos and text when required.

Do not force three variants. Produce one primary specification. Add one alternative only when it tests a materially different visual argument and the user needs that decision.

## Emit the specification

Write:

- visual argument;
- source element ID and borrowed mechanism;
- Shetty's Desk transformation;
- hero and eye path;
- exact content and claim IDs;
- density and mobile-reading plan;
- brand and logo plan;
- rendering lane and reason;
- prohibited copying or unsupported decoration;
- optional alternative and the different argument it tests.

## Gate the visual

Reject a layout when it needs paragraphs to explain itself, hides the decision, duplicates the caption, uses an uninspected reference, implies unsupported data, becomes a generic card grid, or cannot be read at LinkedIn feed size.

Promote only an explicitly approved still to `visual.png`. Leave `gif-storyboard` unchanged and use it only after the existing motion eligibility gate passes.
