## 2. Caption Intelligence

**Opening move:** tool usefulness reframed around artifact, not answer  
**Audience promise:** show how to move from "what is the EOQ number?" to "what trade-off does this batch size carry?"  
**Authority signal:** practical planning inputs: demand rate, setup/changeover cost, holding cost, MOQ, capacity calendar, shelf life, service risk, current batch size, planner assumptions  
**Value artifact:** batch-size decision board / option table / verification checklist  
**CTA/save trigger:** ask whether the team knows which batch size still carries the right trade-off when demand changes

## 3. Adaptation To Shetty's Desk

**What to borrow:** Ref 5's complete inventory formula structure, Ref 7's decision-model table discipline, Ref 25's metric/formula density, Ref 51 and 70's AI-workflow usefulness, and Ref 76's structured assessment feel  
**What to avoid copying:** a basic formula cheat sheet, a generic dashboard, a SaaS-style calculator UI, a fake optimization score, or a visual that pretends the formula is the final decision  
**Supply-chain translation:** the formula becomes useful only when it feeds planner-readable trade-offs: smaller/current/larger batch, setup burden, inventory exposure, capacity fit, service risk, and verification  
**Tiger-specific angle:** batch size is not a pure math answer; it is a decision about which operating cost and risk the business is choosing to carry  
**Best-fit calendar topics:** Optimal batch size; EOQ; production planning; capacity planning; safety stock; reorder point

## 4. Prompt Inputs

**Visual mechanics to borrow:** large formula/test block, variable legend, cost-curve trough, option comparison lanes, interpretation band, verification strip, two-tone title, precise grid, and useful micro-labels  
**Reference lesson for caption:** lead with the gap between formula output and planning decision, then name the input pack and the artifact ChatGPT can build
