## 1. Image Intelligence

**Power format:** process flow + PF8 anatomy + PF4 complete reference  
**Eye path:** start with a bold two-tone title, move through a dominant demand-to-factory translation artifact, then scan constraint modules and output modules as a connected system  
**Hero element:** transparent acrylic translation bridge / planning console on a premium white factory-planning desk  
**Density level:** dense-saveable but not cluttered  
**Repeated cell schema:** use modules, but avoid a flat equal-card grid. The artifact should use distinct visual logic: input stack, constraint gate, trade-off balance, production-plan board, schedule rail, and feedback loop.  
**Proof device:** manufacturing-planning specificity: capacity, materials, labor, changeovers, production plan, factory schedule, feedback  
**Save mechanism:** a reader can save the image as a demand-to-build map for explaining why demand changes cannot always be accepted as-is

## 2. Caption Intelligence

**Opening move:** comparison gap / plain meeting-room premise  
**Audience promise:** explain why the production plan is the missing translation layer between what the business wants and what the factory can actually commit to  
**Authority signal:** practical terms from planning work: demand plan, production plan, schedule, capacity, materials, labor, line sequence, changeover, commitment  
**Value artifact:** demand-to-build process map  
**CTA/save trigger:** ask which constraint changes the plan first when demand changes

## 3. Adaptation To Shetty's Desk

**What to borrow:** the manufacturing process-map clarity of Ref 2, the forecast-to-planning boundary discipline of Ref 13, the one-page artifact ambition of Ref 19, and the practical director-level premise of Ref 51  
**What to avoid copying:** generic ERP hub diagrams, flat comparison tables, repeated icon cards, or a sterile AI control-room background  
**Supply-chain translation:** demand becomes a production plan only after constraints and trade-offs are checked  
**Tiger-specific angle:** the conflict is rarely that operations is being difficult; it is that the plan is now colliding with real capacity, materials, labor, and sequence constraints  
**Best-fit calendar topics:** W30 production planning; production plan; scheduling horizon; sequence to cut changeover

## 4. Prompt Inputs

**Reference lesson for GPT Image 2:** create a premium manufacturing-planning artifact that makes the translation step visible; it should feel like a useful desk object from the same Shetty's Desk design studio as SC OS, but with a different architecture.  
**Visual mechanics to borrow:** process-map rails, input/output gates, center translation object, constraint checks, right-side factory-output rail, small labeled physical props, bottom feedback loop.  
**Reference lesson for caption:** open with the gap between demand ambition and factory commitment, then explain why the production plan protects execution.  
**Reference lesson for topic selection:** basic production-planning topics win when they help the reader explain cross-functional conflict, not when they only define the term.
