**One-sentence visual move:** Five tactile review docks each transform one class of evidence into a named hand-off, then converge into one raised executive decision table.  
**Dominant shape/metaphor:** a premium physical decision amphitheater with five briefing docks and one executive table.  
**Eye path:** two-color headline -> five numbered review docks -> converging rails -> executive table -> readiness equation -> authorship logo.

**Value-density layer:** each review carries a lead owner, one `SETTLE` line, and one `HAND-OFF` line; the executive table carries only the decisions that remain.
