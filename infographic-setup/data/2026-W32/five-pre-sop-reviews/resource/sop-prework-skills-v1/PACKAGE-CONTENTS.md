# Individual Download Library v1.2.0

The website presents exactly seven named individual files: one instruction PDF, one Markdown guide, and five standalone skills. Users apply the skills to governed copies of their own project files; no bundled data, completed answer, installer, or ZIP belongs to the public library.

## Start Here

- `downloads/SOP-PREWORK-START-HERE.pdf` - branded how-to guide covering setup, safe first run, the five review hand-offs, quality checks, and human controls.
- `downloads/SOP-PREWORK-START-HERE.md` - accessible Markdown edition of the same operating instructions.
- `downloads-manifest.json` - machine-readable public download inventory with file names, descriptions, sizes, and checksums.

## Five Standalone Skills

Each public skill file contains the full method, bring-your-own-project setup, data requirements, first-run prompt, guardrails, hand-off gate, and input/output templates in one readable Markdown document.

- `downloads/skills/01-prepare-sop-data-readiness.md`
- `downloads/skills/02-review-sop-portfolio.md`
- `downloads/skills/03-build-sop-demand-plan.md`
- `downloads/skills/04-test-sop-supply-feasibility.md`
- `downloads/skills/05-reconcile-sop-plan.md`

The source skill folders remain under `skills/` only to build and validate the five public standalone files. Public users can attach a standalone Markdown file directly to an AI project or rename it to `SKILL.md` inside the named skill folder. They do not need any other file from this repository.

## Integrity And Safety

- `manifest.json` - full internal source inventory and skill list.
- `checksums.sha256` - SHA-256 integrity checks for source and public files.

No email, account, bundled data, production connection, or system credential is required. Users bring governed copies of their own project files and retain every accountable decision with the named business owner.
