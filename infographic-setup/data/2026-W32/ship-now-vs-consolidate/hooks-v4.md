# Hook routes — Ship Now vs Consolidate

## Selected

**“It'll be ready tomorrow.” Should the truck wait?**

Why it works: it exposes the exact sentence that makes waiting sound safe, then puts the reader
inside the release decision.

## Alternatives

1. **The freight quote says wait. The customer date may not.**
2. **“It should be ready tomorrow” is not a date you can release freight against.**
3. **A cheaper combined shipment can be the expensive customer decision.**
4. **The best freight saving is worthless if it spends the only safe departure.**

Do not use a generic question such as Which order gets to wait? It removes the physical release
moment that gives the post its stakes.
