# C3 route parked — 2026-08-04

The `ship-now-vs-consolidate` public-content route is deliberately parked. No source file in this
folder is an active LinkedIn visual or caption candidate.

## What remains valuable

- The calculator is retained as a potential future product test: its customer-first rule, credible
  scenario treatment, input-freshness guard, and KAM + Purchasing Manager exception ownership are
  still useful.
- The research and source record remain available for a later, evidence-led product decision.
- V14 retains one transfer-learning point: an invisible input must make a physical difference in a
  visual.

## Why the public route stopped

V14's miniature conveyor/gate/clock world needed too much decoding before a reader could name the
proposition. Its visual craft did not compensate for the generic story. The next flagship moved to
a stronger public case and a story-specific working metaphor instead of another iteration here.

No historical asset was deleted. Earlier render tests and their reviews remain in this archive so
the team can learn from the failed direction without accidentally reactivating it.
