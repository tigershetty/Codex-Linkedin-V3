# Hook Routes — C3 V7

**Primary hook:**

> One PO is packed. The next one is "ready tomorrow." Freight has found a cheaper combined rate.
> Would you hold the first shipment?

**Alternatives:**

1. A supplier's "tomorrow" is not a release date.
2. The lower combined rate is the easy number. The last safe departure is the decision.
3. Does the second PO clear the customer date, or only the freight quote?
4. Before waiting for the second PO, find the departure you cannot afford to miss.
5. The ready PO is not a buffer for an uncertain one.
6. Purchasing sees the saving. The KAM sees the date. The release needs both.
7. An exception needs an owner. A repeated exception needs a rule review.
