# Hero Illustration Prompt — The Last Defensible Departure

**Mode:** built-in image generation  
**Use case:** `infographic-diagram`  
**Asset type:** no-text editorial hero insert for a deterministic LinkedIn infographic

Create one original editorial supply-chain illustration on a warm cream paper ground (`#F0EBDE`).

Show a single ready warehouse pallet entering a large mechanical railway-style route switch. The
switch creates two clean cobalt rails that continue toward the right. One rail should feel direct;
the second should include a short waiting loop before rejoining the same route. The pallet and
switch are the only hero. Add subtle freight details such as pallet slats, wrapped cartons, a small
release tag without text, rail fasteners, and one abstract square deadline gate at the far right.

Use only electric cobalt ink (`#1F2BE0`) and the cream paper ground. Flat two-colour editorial
risograph / technical cutaway language, square structural geometry, restrained isometric depth,
fine cobalt linework, no gradients, no glossy SaaS finish, no drop shadows, no rounded UI cards.
Keep the top 22%, bottom 27%, and a narrow band through the centre-left visually quiet so exact
headlines, labels, formulae, and stamps can be overlaid later.

No readable words, letters, numbers, logos, emblems, company marks, people, trucks, clocks, euro
symbols, traffic lights, dashboards, charts, coloured accents, watermarks, decorative characters,
or fake interface panels. Do not imitate any referenced creator's artwork or composition. The
illustration must feel like one physical operational metaphor, not a collection of icons.
