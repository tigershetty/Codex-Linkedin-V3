# Flagship Post Card — Ship Now vs Consolidate

**Route:** flagship

**Route class:** Parked proof-of-concept / calculator product lane — not a standard fast post.

**Reader and real work moment:** A planner or buyer has one packed PO, a supplier says a second
compatible PO may be ready tomorrow, and a combined freight rate makes waiting feel sensible.

**Opening tension:** A lower combined rate can be worth waiting for, but only if the customer date is not being used as the buffer.

**The visible proof:** Historical only. V14 made the readiness range physically change a dispatch
world, which is a useful causal-protection test. It did not earn publication: the miniature
conveyor/gate/clock world was generic and the reader had to decode too much before seeing the
proposition.

**The useful keep:** `customer date → safe departure → latest credible supplier edge → freight rate`. The reader can use this order before comparing a freight saving; if neither route protects service, the exception needs joint KAM and Purchasing Manager ownership.

**Saved references used:** V3 MPS commitment object for a physical boundary; V3 Batch Size Decision Board for a complete teaching instrument; Top-100 reference 33 for feed-speed contrast; reference 65 for causal flow; reference 5 for a self-contained saveable model.

**Three creative families tested:** A: commitment-object product rig; B: timing/uncertainty
corridor; C: V3 instrumented decision board. Those historical tests are preserved as learning
evidence. V12 showed a time boundary but still read too much like a generic landing-page hero. V13
and V14 made a causal correction, but the result still did not carry an audience-worthy visual
proposition at feed speed.

**Current decision:** Parked. C3 remains useful as a calculator/product test, but is not the next
public flagship. The next visual candidate must begin with a stronger public story and a specific
working metaphor or forensic evidence object—not another variation of this diorama.
