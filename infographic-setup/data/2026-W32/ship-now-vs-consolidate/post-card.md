# Flagship Post Card — Ship Now vs Consolidate

**Route:** flagship

**Route class:** Flagship / V3 visual-identity brand-lab exception — not a standard fast post.

**Reader and real work moment:** A planner or buyer has one packed PO, a supplier says a second
compatible PO may be ready tomorrow, and a combined freight rate makes waiting feel sensible.

**Opening tension:** A lower combined rate can be worth waiting for, but only if the customer date is not being used as the buffer.

**The visible proof:** A native **Counterfactual Dispatch Diorama** makes the actual conflict physical: A is ready now on the green customer-safe route, B arrives through a coral credible-ready range, and the counterfactual held A is visibly locked in a two-load bay after the last-safe-departure shutter closes. The readiness trace changes the world rather than merely carrying a label.

**The useful keep:** `customer date → safe departure → latest credible supplier edge → freight rate`. The reader can use this order before comparing a freight saving; if neither route protects service, the exception needs joint KAM and Purchasing Manager ownership.

**Saved references used:** V3 MPS commitment object for a physical boundary; V3 Batch Size Decision Board for a complete teaching instrument; Top-100 reference 33 for feed-speed contrast; reference 65 for causal flow; reference 5 for a self-contained saveable model.

**Three creative families tested:** A: commitment-object product rig; B: timing/uncertainty corridor; C: V3 instrumented decision board. Those historical tests are preserved. V12 showed a time boundary but still read too much like a generic landing-page hero. V13 then opened a distinct V3 visual family—Counterfactual Dispatch Diorama—and V14 was its one bounded causal correction: A/B distinction, a material readiness range, a shared departure boundary, and a visibly held counterfactual load.

**Selected route and why:** V14 — Trace-led Operational Cinema. The scene makes the decision pressure visible as an Operating Trace: B’s credible readiness range physically reaches the departure boundary and changes the outcome for held A. It is a coherent miniature operating world rather than a generic board or generic logistics scene. This is a creative family, not a permanent 3D template; a Commitment Object, formula card, atlas, chart, or other expression remains valid when it makes the work clearer.
