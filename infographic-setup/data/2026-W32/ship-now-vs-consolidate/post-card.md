# Flagship Post Card — Ship Now vs Consolidate

**Route:** flagship

**Route class:** Flagship / V3 visual-identity brand-lab exception — not a standard fast post.

**Reader and real work moment:** A planner or buyer has one packed PO, a supplier says a second
compatible PO may be ready tomorrow, and a combined freight rate makes waiting feel sensible.

**Opening tension:** “Ready tomorrow” is not a supply commitment when the customer date cannot afford the wait.

**The visible proof:** A native **Time-to-Wait Tableau** makes the actual constraint physical: a ready truck, a bounded credible-ready range for PO B, a transparent last-safe-departure plane, and a customer need-by terminal. The range visibly crosses the plane, so the scene itself changes the permitted action to `RELEASE NOW`.

**The useful keep:** `customer date → safe departure → supplier range → freight rate`. The reader can use this order before comparing a freight saving; if neither route protects service, the exception needs joint KAM and Purchasing Manager ownership.

**Saved references used:** V3 MPS commitment object for a physical boundary; V3 Batch Size Decision Board for a complete teaching instrument; Top-100 reference 33 for feed-speed contrast; reference 65 for causal flow; reference 5 for a self-contained saveable model.

**Three creative families tested:** A: commitment-object product rig; B: deterministic timing/uncertainty corridor; C: V3 instrumented decision board. Independent review found C's boundary was labelled but not causally demonstrated, so V11/V12 became one declared brand-lab correction: a cinematic time-to-wait tableau with a different visual primitive—not an open-ended fourth production loop.

**Selected route and why:** V12 — Operational Constraint Cinema. The scene makes evidence → boundary → permitted action visible in a coherent miniature operating world, rather than asking the reader to interpret a generic board. The family is not a single 3D prop or a permanent grid; a Commitment Object, formula card, atlas, or other instrument remains valid when it makes the work clearer.
