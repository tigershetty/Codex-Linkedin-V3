# Native-image prompt — The Supply Chain Translator Map

**Use case:** infographic-diagram

**Asset type:** 4:5 LinkedIn editorial visual

**Reader and live moment:** An early- or mid-career supply-chain practitioner knows they are told
to become cross-functional but has no usable way to choose what to learn next.

**Visible tension:** Six specialist functions are close enough to collaborate but speak different
working languages. The visual turns vague advice into a physically readable translator map.

**Primary request:** Create a single original image-engine-native 4:5 LinkedIn editorial visual.
It is a tactile, modern fold-out field map on a warm off-white paper surface, photographed from
directly overhead. The sheet is a complete, uncluttered six-node operating map, not a dashboard,
not an isometric scene, and not a generic business infographic.

**Central visual mechanism:** Six distinct, clean map stations connected in a continuous clockwise
path. Use these exact, short, large labels only: `BUY`, `PLAN`, `MAKE`, `MOVE`, `DATA`, `STRATEGY`.
Beside every station, show one small, legible direction phrase in a different ink treatment:
`read demand`; `see capacity`; `protect delivery`; `hear the customer`; `serve the decision`;
`know the workflow`. The connections should feel like hand-drawn route lines passing naturally
through the folds of a real working map. One bright red “you are here” pin sits at BUY, but the map
must work for every reader, so it is visibly removable rather than implying a universal start.

**Exact integral title:** `LEARN ONE FUNCTION BEYOND YOUR OWN`

**Exact integral subline:** `A working map for becoming cross-functional`

**Useful rule, printed small but legibly as one sentence:** `Follow the next decision your work affects.`

**Style and materials:** Editorial product photography of a designed field guide; understated
Swiss-map clarity mixed with warm analog stationery; tactile fold creases, fine ink route lines,
one red locator pin, charcoal type, muted functional colors used only for navigation. Generous
negative space. No brand logo, no watermark, no cliché globes, no stock people, no laptops, no
neon, no 3D/isometric objects, no UI panels, no cards, no charts, no generic AI imagery.

**Composition:** 4:5 portrait, feed-first. Title has dominant hierarchy in upper third; map fills
the remaining area. Clear single reading route: title -> locate a function -> follow one route ->
rule. Ensure every heading is sharply legible at mobile size. Render as a single coherent native
image, with no separate title overlay.

**Claim integrity:** This is a bounded conceptual framework. It must not contain career outcomes,
rankings, numbers, company names, logos, or claims that these links are universal.

**Anti-copy boundary:** Do not copy the composition, wording, creator identity, brands, palette,
or artwork of any saved reference. Use the reference shelf only for abstract mechanisms: visible
progression, shared hand-off, warm recognition, and a grouped reference object.
