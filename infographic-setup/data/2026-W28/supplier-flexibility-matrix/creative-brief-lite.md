# Creative Brief Lite — Supplier Flexibility Matrix

**Week:** 2026-W28  
**Slug:** supplier-flexibility-matrix  
**Series:** AI for Supply Chain  

## 1. Audience Value

**Audience segment:** supply planners, category managers, procurement managers  
**Audience job:** save time  
**After reading, they can:** build a supplier flexibility matrix before a demand spike exposes weak options.  
**Meeting/task/career moment:** demand spike review, allocation meeting, supplier escalation, scenario planning.

## 2. Stop-Scroll Promise

**Opening claim:** Can this supplier absorb the spike?  
**Why this stops the right reader:** it names the exact question planners face when demand moves faster than supplier capability is understood.  
**Save trigger:** template

## 3. Reference Intelligence

**Power format:** PF7 ranked cards + matrix  
**Structure reference lesson:** turn supplier flexibility into a ranked matrix artifact with repeated row logic.  
**Caption promise lesson:** use a role-pain opener and then give the matrix the reader can reuse.  
**Caption index ref:** refs 87, 70, and 5 ranking/workflow/save-trigger patterns adapted to supplier flexibility.  
**Craft/brand lesson:** use Cobalt Grid as a dense ledger: rows, columns, mono tags, and one clear verification strip.

## 4. Visual Argument

**One-sentence visual move:** Show suppliers ranked by flexibility across volume swing, response time, MOQ, constraints, and confidence, with Claude structuring the matrix and the planner verifying capacity.  
**Dominant shape/metaphor:** ranked flexibility matrix  
**Eye path:** headline -> matrix rows -> Claude workflow strip -> verification warning  
**Reusable artifact on image:** supplier flexibility matrix template
**Value-density layer:** Each supplier row should feel like a usable review artifact: filled/hollow score marks by criterion, rank badges, row status emphasis, verification icons, evidence ticks, risk gaps, and a subtle mini-legend. Force one clear decision path: Supplier A is the only Call first row, Supplier B and Supplier C are Backup rows, and Supplier D and Supplier E are Watch risk rows. Risk rows must visually fail or require verification; do not mark every supplier Ready.
