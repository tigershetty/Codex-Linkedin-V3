# GPT Image 2 Studio Base Prompt — Supplier Flexibility Matrix

**Purpose:** Generate a professional, high-end design-studio base image for deterministic text/logo overlay. This prompt intentionally avoids final microtext, mascots, and fake dashboard UI.

## Prompt

Create a premium editorial hero image for a LinkedIn supply-chain infographic about supplier flexibility during a demand spike.

Show a physical supplier capacity stress-test table in a clean control-room / design-studio environment. A glowing orange demand spike enters from the upper right and presses into five miniature supplier platforms arranged across a dark logistics map table. Supplier A visibly absorbs the spike through a strong cobalt route and a stable load-bearing platform. Supplier B and Supplier C carry partial load as secondary routes. Supplier D and Supplier E are pale, constrained, cracked, blocked, or awaiting verification.

The hero object is the stress-test table itself. Make it feel like a professional industrial design model: miniature warehouses, docks, pallets, trucks, supplier bays, route lines, gauge sockets, load-bearing rails, tiny constraint blocks, and physical diagnostic marks. The visual should explain the decision through structure, materials, and route strength, not through lots of text.

Each supplier platform should have five tiny diagnostic sockets or gauge marks representing:
- volume swing
- response time
- MOQ
- constraint
- confidence

Do not render readable microtext inside the scene. Leave clean blank cream/cobalt annotation plates beside each supplier platform for deterministic labels later. Leave clean top space for a headline and subheading overlay. Leave a clean footer zone for Shetty's Desk brand chrome and logo overlay.

Visual decision logic:
- Supplier A = strongest, stable, bright cobalt route, call first
- Supplier B = useful secondary route, backup
- Supplier C = useful secondary route, backup
- Supplier D = weak or constrained route, watch risk
- Supplier E = weakest or unverified route, watch risk

Style:
High-end editorial design studio, tactile miniature model photography mixed with restrained graphic annotation. Warm cream paper border, electric cobalt grid, square technical labels, thin hairlines, matte materials, crisp physical lighting, measured shadows, premium print-design restraint. Use one small orange accent only for the incoming demand spike.

Avoid:
No animal, no mascot, no creature, no fake HUD, no glossy SaaS dashboard, no rounded app cards, no neon overload, no long text blocks, no invented labels, no invented numbers, no fake logos, no salaries, no role sections.

Composition:
4:5 portrait LinkedIn image. The stress-test table should dominate the frame and be instantly readable at feed size. The demand spike, five supplier platforms, and A/B/C/D/E state differences must be obvious before any text overlay is added.
