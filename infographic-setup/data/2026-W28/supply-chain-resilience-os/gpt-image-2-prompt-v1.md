# GPT Image 2 Prompt v1

Use case: productivity-visual / infographic-diagram  
Asset type: LinkedIn 4:5 portrait infographic for Shetty's Desk

Create a world-class premium one-page supply chain operating artifact titled exactly: "SUPPLY CHAIN RESILIENCE OS".
Subtitle exactly: "A one-page operating system for seeing risk, choosing response, and learning faster."

Visual thesis: the artifact itself is the hero. It should feel like a high-end design studio produced a boardroom-ready reference sheet that a supply chain leader would save before a disruption review. Do not make a generic dashboard. Do not make a decorative animal mascot. Do not make a loose collage. Make it a dense, beautiful, usable reference artifact.

Brand direction from Shetty's Desk:
- Clean, airy, modern, credible, optimistic.
- White / very pale blue canvas.
- Primary colors: azure blue #2798FB, deep ink #15315C, navy #1939A5.
- Signature progress accent: eco green #38E6A6.
- Warning accent used sparingly: coral #E27199.
- Isometric 2.5D vector style with soft gradients, no photorealism, no dark background.
- Add a small footer watermark/brand mark: a textured chalk ring above the words "Shetty's Desk". Keep it small and tasteful.
- Add a small top-right chip: "BUILT WITH CLAUDE" with a simple monochrome sparkle mark, but do not let the chip dominate.

Composition:
- Portrait 4:5, mobile-first.
- Large editorial headline at top.
- The center 70% of the image is a premium one-page operating system poster pinned on a bright desk, with tiny isometric supply chain objects around it: supplier factory, port, warehouse rack, truck, customer node, risk radar.
- The operating system poster has 7 distinct mini-frameworks, each with a different visual metaphor, inspired by premium one-page strategy artifacts:
  1. ORCHESTRATE: hub-and-spoke control node.
  2. PLAN: demand wave with capacity line.
  3. SOURCE: supplier tiers / network map.
  4. TRANSFORM: factory flow with bottleneck marker.
  5. FULFILL: route lane with delivery checkpoints.
  6. RECOVER: recovery curve comparing time-to-survive and time-to-recover.
  7. LEARN: feedback loop from incident to new rule.
- Use the exact section labels above, large enough to read.
- Add one narrow side strip titled exactly: "3 MODES" with three stacked chips: "Persist", "Adapt", "Transform".
- Add one bottom strip titled exactly: "THE REVIEW LOOP" with four steps: "Monitor -> Assess -> Recover -> Evaluate".
- Add small source/footer line exactly: "Source frame: SCOR DS + resilience research · Shetty's Desk".

Information design:
- Each mini-framework should have its own geometry: wheel, wave, network, flow, curve, loop, or map. No repeated identical cards.
- Dense but not cramped. Leave enough whitespace between modules.
- Use leader lines and tiny annotations sparingly. Avoid large UI cards floating over the scene.
- Text must be crisp, professional, and legible. No nonsense letters, no misspellings, no lorem ipsum, no fake dense body paragraphs. Use only the text specified above plus tiny realistic numeric ticks like "TTS" and "TTR".
- The visual should pass the thumbnail test: at feed size, the reader sees "SUPPLY CHAIN RESILIENCE OS" and a complete one-page operating system.

Style references to synthesize without copying:
- Eric Partaker one-page framework density: many bespoke mini-frameworks in one useful artifact.
- Premium consulting exhibit discipline: action-title, direct labels, source band, restrained accent.
- Shetty's Desk brand: luminous blue, green progress highlight, coral warning only where something breaks, isometric supply chain motifs.

Avoid:
- generic SaaS dashboard, glassmorphism, stock icons everywhere, excessive purple, dark cyberpunk, photorealistic octopus/animal hero, unreadable tiny text, AI-looking random labels, fake logos, cluttered callout boxes, repeated template grid.
