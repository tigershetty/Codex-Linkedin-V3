# Visual Postmortem — Demand Planning Decision Book

**Date:** 2026-07-03  
**Status:** Not accepted  
**User verdict:** still too cartoony; not at Supply Chain Resilience OS caliber  

## What Went Wrong

The workflow documented the Holy Grail standard, but the early Demand Planning render did not actually enforce the full Holy Grail input stack. It used the demand-planning content logic, but the visual renderer drifted into a warm cream/open-workbook direction instead of the accepted luminous Supply Chain Resilience OS visual grammar.

The later v9-v11 attempts restored the correct reference stack and palette, but still missed the craft bar. They got closer on structure and color, yet the finish became too clean, toy-like, and vector-template. It lacked the more elevated artifact depth, authored texture, and premium desk staging that made Supply Chain Resilience OS feel like a design-studio piece.

## Root Causes

1. **Documentation was treated as enforcement.** Updating reference files did not guarantee the actual render prompt used the accepted benchmark inputs.
2. **The prompt compiler was too generic.** It allowed "warm cream paper" and generic editorial infographic language to compete with the Holy Grail luminous palette.
3. **The audit measured file completeness more than visual taste.** The package could pass even when the image did not meet Tiger's qualitative bar.
4. **Self-review inflated the result.** The review marked v11 as 5/5 even though the user verdict proved it should have remained a candidate.
5. **Text correction became production cleanup.** Title and label fixes solved hard failures but did not raise the underlying craft level.
6. **The wrong success criterion was used.** "Same references and palette" was treated as enough, when the real target is same caliber: finish, depth, hierarchy, texture, and status.

## New Quality Rule

For Holy Grail-level posts:

- The accepted Supply Chain Resilience OS visual must be attached or visible as a reference every time.
- Ref 19 is the primary density/craft reference for one-page artifact visuals.
- Topic-specific refs provide content logic only, not the dominant visual style.
- Warm workbook, beige scrapbook, simple card-grid, and toy-icon vector outputs are rejected directions.
- A visual cannot be called final if Tiger's taste verdict says it is not there yet.

## Next Render Direction

The next Demand Planning render should:

- preserve the Holy Grail luminous palette,
- reduce cartoon icon weight,
- make the artifact feel like a premium physical strategy poster, not a vector worksheet,
- use subtler dimensional desk staging,
- add authored micro-detail through lines, modules, curves, gauges, and texture,
- keep the demand-planning logic but make the finish more elevated and less literal.

## Practical Process Change

Future flagship visuals should move through these statuses:

1. `candidate` — generated, not yet taste-approved.
2. `shortlisted` — passes basic text and structure checks.
3. `accepted` — Tiger-approved against the benchmark.
4. `visual.png` — only after accepted status.

The current Demand Planning image should be treated as a candidate, not the final design answer.
