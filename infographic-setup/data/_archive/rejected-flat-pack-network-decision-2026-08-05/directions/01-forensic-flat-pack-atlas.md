# Direction A — Forensic Flat-Pack Atlas

**Role:** visual idea — selected

- **First-frame hook:** one unbranded flat-pack carton is opened like a museum-grade technical
  specimen and has become two supply networks.
- **Working mechanism:** its centre fold is a real network hinge. On one side, tightly nested panels
  lock into a calm container/ocean path; on the other, the same material fans toward a regional
  factory and short response path. Four material stress markers at the hinge imply the review lens:
  cube, duty, volatility, and response time.
- **Useful keep:** product design is a network variable; run the sourcing question per SKU.
- **Why it is original:** it turns a public case into a physical evidence object rather than an
  illustration of IKEA, a nearshore map, or a generic comparison card.
- **Kill condition:** kill if the object reads as a generic shipping carton, a literal global-versus-
  local split screen, or needs labels to show that the product itself is causing the network choice.
