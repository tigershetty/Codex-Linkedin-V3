# Hook Routes v2 — One Source Country, Five Network Decisions

**Recommended LinkedIn opener**

> Two SKUs can leave the same country and still create two entirely different network decisions.

This is the clearest bridge from a familiar sourcing conversation to the image’s visual proof.

## Alternatives

1. A flat-pack box changes more than freight efficiency. It changes the options available to the network.
2. One origin can support several viable networks, depending on what each SKU asks of the system.
3. Before comparing countries, look at what each SKU is asking the network to carry.
4. The country can remain the same while the right network changes completely.
5. Packaging is already part of the sourcing decision, whether it appears in the review or not.
6. Some products earn the distance; others make the distance expensive.
7. The source-country question becomes much clearer once the SKU enters the room.
8. A compact product and its bulky neighbour can require very different network answers.

## Use rule

Choose one hook only. The visual already delivers the proposition, so the caption should open the
story rather than restate the headline in another form.
