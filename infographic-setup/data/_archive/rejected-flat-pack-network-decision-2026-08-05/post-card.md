# Flagship Post Card — One Source Country, Five Network Decisions

**Route:** Flagship / evidence-led public operating case

**Renderer:** Image engine native (GPT Image 2).

**Reader and real work moment:** A planner, buyer, or transformation leader is reviewing global versus
regional sourcing and the conversation has started as a country-level binary instead of a
SKU-level operating decision.

**Opening tension:** Two SKUs can leave the same country and still create two entirely different
network decisions.

**The visible proof:** One shared brushed-metal source hub sends five materially different,
unbranded SKU specimens into distinct blue, green, and coral route fields. A fragile volume-heavy
SKU physically stops at a coral boundary, so the reader can see constrained viable reach rather than
being asked to infer it from a label.

**The useful keep:** One source country can produce different network decisions; re-test a portfolio
by SKU across pack density, landed cost, duty exposure, volatility, viable capacity, and
response-time value.
