## Power Format Mechanics Seeds

Use these as the first visual-mechanics seed before selecting exact image references. The reference card for a post should still name the exact refs used.

| Format | Stop-scroll shape | Mechanics seed |
|---|---|---|
| PF1 Maturity / zone ladder | levels, bands, or zones | vertical progression, locked/flexible bands, next-step arrows, status badges, one "you are here" cue |
| PF2 Comparison / versus | split contrast | left/right or before/after fields, mirrored labels, one decisive difference line, shared baseline, asymmetric outcome cue |
| PF3 KPI / formula card | calculation object | large formula/test block, variable legend, small worked example, interpretation band, caveat strip |
| PF4 Cheat-sheet / diagnostic grid | complete reference | grouped cells, repeated micro-schema, section bands, icon cues, bottom "use this when" strip |
| PF5 Radial hub / feature map | center-to-use-case map | central tool/system hub, spokes into role tasks, grouped rings, practical use-case cards |
| PF6 Decision tree / decision test | choice route | yes/no or threshold gates, branch endings, decision labels, caveat checkpoints |
| PF7 Ranked cards / index | ordered priority | rank badges, repeated row schema, progress bars, severity/status tags, side facts |
| PF8 Anatomy / labeled diagram | exploded artifact | hero object/card, labeled layers, callout rails, zoom-in detail blocks, what-to-check strip |
| Process flow | end-to-end movement | staged path, handoff arrows, input/output gates, exception loop, final decision node |
| Concept metaphor | sticky reframe | one structural object, visual tension, minimal labels, practical test or question at the bottom |

## Ref 5 — Dense Formula / Complete Reference Card

**File:** `references/top 100/5.jpeg`  
**Caption mechanic:** misconception correction + save for next planning cycle  
**Visual mechanics to borrow:**
- Large two-tier headline: broad topic first, practical outcome second.
- Three primary modules across the top, each with number badge, icon, formula/test box, plain-language use case, and variable legend.
- One wide explanatory diagram beneath the modules that makes the concept operational.
- Worked example block below the diagram with inputs on the left and calculated outputs on the right.
- Bottom utility strip that answers "what each piece solves."

**Best Shetty translation:** use for formula cards, decision tests, supplier review checks, and 101 explainers where the post should feel complete enough to save and reuse.

## Ref 70 — AI Workflow / Capability Map

**File:** `references/top 100/70.jpeg`  
**Caption mechanic:** "not the tool, how you set it up" workflow argument  
**Visual mechanics to borrow:**
- Hero title + plain-English promise line.
- Top legend that groups the system into capability layers.
- Many small feature cards connected by dotted rails so the image feels like a system map, not loose tips.
- Each card has a short title, small icon, one practical description, and 2-4 bullets.
- A dark/high-contrast proof block near the bottom that states the shift or thesis.
- Footer CTA/identity strip separated from the main content.

**Best Shetty translation:** use for AI-for-SC workflow maps, tool setup guides, prompt libraries, and "how to operationalize AI" posts.

## Ref 87 — Ranked Index / Exposure Map

**File:** `references/top 100/87.jpeg`  
**Caption mechanic:** ranked list + saveable index  
**Visual mechanics to borrow:**
- Big title followed by a row of summary metric tiles.
- "How to read this index" legend before the ranked rows.
- Repeated horizontal row schema: rank badge, role/item title, status tag, progress bar, why line, split task boxes, side facts.
- Color-coded bands communicate severity before the reader reads details.
- Each row includes both risk/exposure and human/action nuance, making the ranking feel credible.
- Footer promise invites the reader to get the full toolkit/checklist.

**Best Shetty translation:** use for supplier rankings, risk exposure maps, AI suitability by role/process, flexibility matrices, and any ranked operating index.

Every flagship prompt should include one sentence of visual mechanics:
