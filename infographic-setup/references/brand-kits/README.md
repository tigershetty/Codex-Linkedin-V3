# Shetty's Desk Brand Expression Registry

| Expression | Status | Use when | Do not use when |
|---|---|---|---|
| `shettys-desk-operating-studio` | **Default** | a reader needs to see a live operating tension, decision mechanism, useful system, transformation, or role hand-off | a spare two-colour editorial statement is clearly the better argument |
| `cobalt-grid` | Explicit secondary choice | the argument benefits from a sparse, research-note, ledger, or single-framework editorial treatment | a physical operating scene, decision tool, or first creative test needs stronger visual tension |

Choose the expression in the creative brief. Brand expression is a reader-comprehension decision,
not a decorative afterthought. The default uses `Brand Kit/brand-tokens.json`; neither expression
permits redrawing the owned logo or copying a saved creator's look.
