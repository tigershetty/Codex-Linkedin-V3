# Fast Post Loop v1

**Status:** active default for ordinary LinkedIn posts

## Why it exists

Five posts a week cannot be five miniature consulting engagements. This loop protects the useful
creative work and removes the paperwork that was delaying it.

Use this for an ordinary LinkedIn post. Use the full Creative Genome package only when the post is
a flagship, contains a substantial evidence claim, or needs a real downloadable artifact.

## The 75-minute ceiling

| Time | Do only this |
|---|---|
| 0-10 minutes | Write a four-line post card and pull two to four relevant saved references from the current shelf. |
| 10-20 minutes | Make three prompt cards: hook, visible proof, and saveable keep. They are rough ideas, not rendered layouts. |
| 20-25 minutes | Select or kill. If none wins, park the topic. |
| 25-70 minutes | Build one selected image-engine-native visual and its complementary caption. |
| 70-75 minutes | Run the five reader checks and stop. |

Do not start a calculator, research dossier, full reference bundle, detailed concept board, or
three finished visual tiles before minute 25. Those belong to the flagship route only.

## The post card

One file, post-card.md, is the source of truth for a standard post:

    Reader and real work moment:
    Opening tension:
    The visible proof:
    The useful keep:
    Saved references used:
    Three rough routes:
    Selected route and why:
    Active visual:
    Active caption:
    Claim boundary:
    Publication status: draft / approved by Tiger / published

The active visual and caption paths are explicit. A check may never silently review an older
visual.png simply because it happens to exist.

## The five reader checks

1. **Stop:** Would the right reader recognise the situation in three seconds?
2. **Show:** Does the image itself show the tension, rather than a caption explaining it?
3. **Keep:** Is there one useful rule, map, or distinction worth saving?
4. **True:** Are the visible claims proportionate to the support we actually have?
5. **Tiger:** Does the caption sound like a person making a clear point, not a generic explainer?

One critical no means revise once or park it. Never use extra production effort to disguise a weak
story.

## Rendering rule

For a standard Operating Studio post, the final visual is rendered natively by the image engine.
Do not paste HTML, SVG, dashboard cards, or a title layer over an image to make it feel finished.
The scene, hierarchy, text treatment, and visual tension must be one rendered composition.

An exact spreadsheet, field guide, calculator, or document may be a separate artifact when it adds
genuine utility. It is not a compulsory lower strip bolted onto a social visual.

## Flagship route

Escalate to the full Creative Genome route only when one of these is true:

- a new creative family needs a fresh 10-15 reference exploration;
- a numerical, company, research, or current-tool claim needs a detailed evidence trail;
- a public artifact will be used repeatedly;
- the post is a brand-defining flagship, Substack issue, or website resource.

The flagship route uses the existing reference bundle, recombination brief, claim ledger, and full
production audit. It must declare itself as flagship; it is never the automatic default.
