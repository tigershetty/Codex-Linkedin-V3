# Pre-Creative-Genome V4 Archive — 2026-08-02

These files are preserved for learning and provenance. They are not active production authorities.

They were archived because they installed one or more constraints that conflicted with the V4 reset:

- numeric topic scoring before creative exploration;
- Top-100 references as optional, post-qualification decoration;
- static calendar-to-reference mappings;
- a universal research burden regardless of the claim;
- 3D/isometric or legacy visual systems as the flagship default;
- duplicated visual authorities that competed with Cobalt Grid;
- synthetic examples as the default path to a complete resource.
- renderer-specific pilot plans that predated direction-first renderer selection.

Useful layouts, examples, and lessons may be extracted into the Creative Genome. Do not cite an
archived file as current workflow authority.
