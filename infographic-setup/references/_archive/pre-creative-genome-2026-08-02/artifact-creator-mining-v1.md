# Artifact Creator Mining v1

**Created:** 2026-07-02  
**Purpose:** Translate high-performing creator, consulting, research, and supply-chain references into a repeatable GPT Image 2 brief pattern.
**Holy Grail update:** `holy-grail-visual-standard.md` now turns the `supply-chain-resilience-os` result into the active flagship benchmark.

## 1. Core Shift

The strongest visual direction is not "make an infographic about the topic."

The stronger prompt is:

> Make a premium one-page operating artifact that a supply-chain leader would save, print, and use in a meeting.

This borrows the save-utility of Eric Partaker-style one-page framework posts, but adapts it to supply-chain operating work: risk reviews, S&OP, supplier recovery, AI-enabled planning, procurement governance, logistics control, and exception management.

## 3. What The Best Artifacts Have In Common

- They promise completeness: "book in one page", "OS", "map", "playbook", "cheat sheet", "decision test".
- They are useful without the caption.
- Each module has a different visual logic, instead of repeating the same card seven times.
- The title is a claim or artifact name, not a neutral label.
- The reader can tell what job the image performs: diagnose, decide, compare, plan, recover, or explain.
- The brand is present as a quiet footer identity layer, not as decoration.

## 4. Production Rule For GPT Image 2

Every flagship prompt should include this block:

```md
ARTIFACT PROMISE:
This is a premium one-page operating artifact, not a generic infographic.

READER JOB:
The reader should be able to use this before [specific meeting/task].

REFERENCE INTELLIGENCE:
- Structure: one-page complete framework artifact.
- Supply-chain backbone: [SCOR / APQC / TTR-TTS / MARE / role-specific workflow].
- Visual craft: consulting exhibit discipline + Shetty's Desk luminous isometric brand.

QUALITY TEST:
At feed size, the artifact name and main structure should be clear.
At zoom size, each module should add practical value.
```

## 6. First Render Audit

What worked:

- Much closer to the "artifact is the hero" direction.
- Title and main promise are readable.
- Shetty's Desk palette and isometric system are respected.
- The seven modules are not identical; they use hub, wave, network, flow, route, curve, and loop patterns.
- It feels more like a saved reference sheet than an AI poster.

What still needs deterministic polish:

- Exact logo lockup should be overlaid from repo assets, not trusted to GPT rendering.
- Some tiny body copy should be replaced with deterministic SVG/HTML text if this becomes a final.
- The source line and footer should be logo-locked.
- The module content should be audited against a truth table before publishing.

Recommended final workflow:

1. GPT Image 2 generates the premium scene and artifact composition.
2. Use surgical edit/post-production only for explicitly requested changes: logo relocation, chip removal, source/footer cleanup, or minor text repair.
3. Preserve the winning angle, 3D depth, desk props, shadows, and artifact layout during cleanup.
4. QA checks text, logo fidelity, source truth, thumbnail clarity, save utility, and Holy Grail fit.
