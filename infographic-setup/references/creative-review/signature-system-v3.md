# Shetty's Desk Signature System V3 — Operational Cartography

**Status:** active visual-signature guardrail for V5. Replaces V2 as the default authority.

## The signature is a behaviour, not a template

Shetty's Desk should become recognisable because it repeatedly turns a difficult supply-chain
moment into a clear, valuable visual thought object. It is not a fixed palette, font pairing,
card system, or mascot.

The ownable behaviour is **Operational Cartography**:

> Make the hand-off, constraint, choice, trade-off, date, signal, owner, or operating system
> easier to see than it was in the meeting.

The reader should feel that a capable peer has made an invisible working problem visible—not that a
consulting deck, AI template, or another creator's post has been restyled.

## V5 production families

| Family | Reader job | Exact production route |
|---|---|---|
| Scene / editorial object | recognise a work moment, tension, or point of view | image-native final |
| Visual Framework | identify, compare, diagnose, navigate, or explain a real working problem | Figma-native exact LinkedIn visual |
| Field Guide | retain a durable, printable, safety-sensitive working reference | Figma-native specialist artifact |
| Tool / calculator | change an input, run a scenario, or reuse a model | spreadsheet, web, or dedicated product |

No family is the default before the reader task and spatial claim are selected. The Visual Framework
is the normal route for an exact, saveable infographic; Field Guide is one specialist subset, not
the brand's public visual posture.

## Fixed behaviours

1. **One clear reader promise.** At feed size, the reader sees a useful outcome or recognisable
   tension—not a category label.
2. **A truthful spatial thesis.** The visual form makes the actual relationship visible: a path,
   comparison, map, stack, spectrum, matrix, sequence, or measured display. Do not create an
   implied order, causality, precision, or ownership that the material cannot support.
3. **High-resolution utility.** Use macro hierarchy plus micro-detail that removes uncertainty:
   conditions, examples, exceptions, variables, labels, decision rights, or source boundaries.
   An arbitrary card wall is not density.
4. **Operational language.** Name the thing a practitioner must handle: need-by, hand-off,
   buffer, source reliability, order quantity, capacity, recovery, promise, constraint, owner.
5. **Deliberate material contrast.** Calm ground, dark ink, and two to five semantic colour roles
   create navigation. A colour must name a state, route, question, evidence class, or exception;
   it cannot merely decorate departments.
6. **An owned semantic anchor.** A tag, tab, annotation, path marker, stamp, field, or selected
   word may become a focal object. It must help scanning and varies by argument. Handwriting is
   not an automatic brand device.
7. **A useful boundary.** Every simplifying framework distinguishes what it helps with from what
   it does not determine. This is working judgement, not a detached disclaimer.

## Variable expressions

Palette, typography, illustration, physical metaphor, density, shape, editorial energy, and motion
should vary when the argument changes. Recognition comes from the quality of thought and the way
the system makes operations legible—not from forcing every post into the same skin.

The following are permitted when they truthfully carry the argument:

- grids, tables, comparison rows, nested regions, small multiples, axes, numbered modules,
  progressive state reveals, paths, ladders, maps, taxonomies, and data displays;
- rich colour grouping where it differentiates useful classes or states;
- precise Figma typography and diagram geometry as the actual social visual;
- a restrained illustration or image-generated material layer when it adds a real cognitive cue.

The following fail the signature:

- a visual shape selected before the relationship it claims to show;
- dashboards, generic SaaS cards, or symmetric tiles used as a decorative container;
- a repeated poster template that makes different topics look interchangeable;
- false data, fake operational proof, or unsupported numerical/causal outcomes;
- motion that merely adorns a complete still rather than revealing a meaningful state change.

## Reference transformation and anti-copy

The supplied Pierri corpus is a high-value reference for editorial judgement: narrow/deep/wide
scope selection, large outcome-first hierarchy, one dominant information object, navigable density,
and motion that reveals state.

It is not a visual identity to replicate. Do not reproduce its identifiable combination of marker
lettering, pastel skin, box geometry, particular composition, moving-ball motif, copy, client proof,
or layout proportions. Generic information-design grammar is available to transform when it serves
a different supply-chain argument, original copy, new geometry, material treatment, and reader
payoff.

## Reader-time contract

| Reader time | The work must earn |
|---|---|
| 3 seconds | the work moment or promised outcome |
| 10 seconds | orientation: what the object shows and how to read it |
| 30–90 seconds | a concrete distinction, check, question, or reference worth keeping |
| return use | useful micro-detail without a contradictory or misleading claim |

Use `v5-working-infographic-production-system.md` for the Visual Framework route. V2 and the
Field Guide Notebook documents remain historical/specialist references; they cannot silently select
the V5 visual language.
