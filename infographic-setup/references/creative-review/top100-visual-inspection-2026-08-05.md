## What is already clear

The set has no single winning aesthetic. Its common thread is a concrete visual job: make a distinction, map a system, sequence a decision, expose a working reference, show an operational before/after, or turn complexity into a compact field guide. The material treatment varies widely—editorial paper, dark product board, dense spreadsheet, illustrated scene, or simple diagram—because **the structure earns attention before the styling does**.

## First working creative families

These are working retrieval families, not a new brand template:

1. **Decision distinction** — compare terms, choices, roles, or maturity levels with a shared schema (`13`, `24`, `33`, `73`, `90`, `96`, `100`).
2. **Operational map** — make a system, hand-off, or architecture visible (`2`, `11`, `39`, `40`, `54`, `69`, `83`, `95`).
3. **Field guide** — give the reader a reference they can use tomorrow (`5`, `22`, `25`, `74`, `77`, `81`, `94`, `99`).
4. **Transformation journey** — show current state, progression, and a better operating state (`29`, `34`, `45`, `46`, `56`, `59`, `67`, `85`, `86`).
5. **Lived-work metaphor** — make a familiar tension emotionally recognisable, then unpack it (`26`, `31`, `35`, `44`, `64`, `65`, `66`, `71`).
6. **Product/workflow proof** — show a real interface, operating loop, or usable asset rather than abstract advice (`17`, `20`, `38`, `47`, `53`, `70`, `72`, `79`, `80`, `97`).

## Implication for V4

The Creative Genome should select a **job and a reader payoff before it selects any visual family**. The new signature system may later set distinctive materials and typography, but it must not flatten all of these into one polished dashboard, isometric scene, or brand-kit template.
