# Top-100 Forensic Records

This directory holds the decision-grade, reference-by-reference analysis of every available local
Top-100 visual. It is intentionally separate from the 480-post foundation ledger:

- Top-100 gives us deep creative source material, including the 38 assets not yet mapped to a saved
  post record.
- The saved-post ledger remains the completeness gate for the 480-post review.
- Captions from `Reference File and Caption.xlsx` are source context only; visual claims come from
  direct inspection of the local asset.

Records are named `TOP100-###.json` and must validate as JSON against the field structure in
`../forensic-record-template.json`. All **97 locally available assets** now have a forensic record;
the 100 workbook caption contexts are preserved separately in
`../top100-forensic-source-context.jsonl`.

The first three records are calibration records. They demonstrate the required depth across a
decision distinction, an identity/metaphor post, and an operational before/after. Remaining records
apply the same topic-neutral mechanism grammar to their directly inspected visual observations and
separate caption context.
