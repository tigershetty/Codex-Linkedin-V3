# Pre-Creative-Genome Script Archive

These scripts are preserved for history and are not active workflow authority.

- `compile-topic-seed.mjs` and `audit-calendar-reference-map.mjs` belong to the retired fixed-map
  and score-first selection route.
- `fetch-linkedin-saves.mjs` passed a LinkedIn session cookie directly on the command line and wrote
  a separate memory-oriented corpus. V4 uses the immutable read-only audit, deterministic Creative
  Genome snapshots, and an approved refresh procedure instead.

Do not run these scripts from active instructions. Reuse useful parsing logic only after adapting it
to the current schemas, provenance rules, and credential handling.
