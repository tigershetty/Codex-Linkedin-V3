# Motion Brief - Did The Override Add Value?

**Post folder:** `data/2026-W31/forecast-value-add/`  
**Source visual:** `data/2026-W31/forecast-value-add/visual-linkedin.png` (`1080 x 1350`)  
**Motion project:** `videos/forecast-value-add-motion/`  
**Status:** production

## 1. Motion Job

**Motion helps this post because:**  
The reader needs to see the three forecast traces establish the comparison, the two WAPE values resolve into FVA, and the result become an override decision in that order.

**Picture-first promise:**  
The approved still remains fully visible throughout and is pixel-identical at the first and final frame.

**Motion archetype:**  
formula + comparison + decision rule + evidence table

## 2. Reading Order

1. Actual demand, human adjusted, and naive baseline establish the evidence.
2. Baseline WAPE and adjusted WAPE resolve into `+5.5 pts` of value added.
3. Positive, zero, and negative FVA resolve into keep, review, or stop actions.
4. The override ledger tests promotion, customer event, and no-evidence examples.
5. The input pack closes on the evidence required to repeat the review.

## 3. Locked Elements

- headline, subheading, and every authored label
- all curves, numbers, formula text, decision words, and table values
- chart, comparator, plates, borders, screws, props, shadows, and perspective
- ChatGPT logo and Shetty's Desk logo
- all structural geometry and background surfaces

No text, curve, number, logo, panel, or physical object moves. Motion is limited to registered source highlights, clipped trace sweeps, and restrained focus rings.

The chart remains a single locked graphic. Only color-isolated source pixels brighten; the authored traces are never reconstructed or displaced.

Headline, explanatory formula text, logos, chart frame, comparator plate, and physical studio surfaces remain locked because reconstructing them would reduce fidelity.

## 5. Signal Plan

There is no freehand signal path. The source traces themselves carry the first three beats through clipped highlight sweeps with halos generated from the exact masks. Restrained focus rings confirm the comparator result, ledger rows, and input pack without covering text.
