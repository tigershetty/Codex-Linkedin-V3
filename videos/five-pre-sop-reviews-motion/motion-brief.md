## 1. Motion Job

**Motion helps this post because:** the reader needs to see five review outputs become decision packets, converge on Executive S&OP, and resolve into one readiness test.

**Value added beyond the still:** the still shows the architecture; motion demonstrates the operating hand-off. It names the output of each review, carries that output along an authored route, separates preparation from executive action, and locks the four readiness ingredients last.

**Motion archetype:** staged 3D assembly + process convergence + decision resolution

## 2. Editorial Sequence

1. Begin on the complete approved still.
2. Transition to a clean architectural stage while the exact headline and logo remain fixed.
3. Assemble each source-cut 3D review station in operating order.
4. Name the hand-off and move one decision packet along its route.
5. Assemble Executive S&OP only after the five inputs exist.
6. Resolve the four executive actions in sequence.
7. Build the readiness equation and lock `EVIDENCE + OWNER + OPTIONS + ASK`.
8. Return to the untouched complete still for reading and the loop.

## 3. Layer Contract

| Layer | Method | Why it is credible |
|---|---|---|
| Complete still | exact canonical `visual.png` | pixel-identical opening and closing endpoints |
| Clean stage | deterministic pale-blue architectural plate | creates real negative space without fake erasure patches |
| Review stations | alpha-isolated source components | preserves the authored 3D objects, exact text, and material treatment |
| Hand-off labels | compact source-derived operating outputs | adds explanatory value without introducing a second dashboard |
| Routes and packets | deterministic SVG paths | demonstrates movement and sequence rather than pointing at pixels |
| Executive actions | four registered decision pips | resolves the exact existing action list without rebuilding the text |
| Readiness rule | exact source strip plus four term markers | turns the equation into a final operating test |

## 4. Locked Elements

- exact headline, subtitle, review text, equation, and Shetty's Desk logo
- all station graphics and source typography inside the extracted components
- final 1080 x 1350 composition
- the meaning and order of every review output

The physical review modules move only as complete source-authored objects. No text is retyped, no logo is approximated, and no raw rectangular crop is animated.
